# Cloud Storage Explorer Project Report

## Abstract

Cloud Storage Explorer is a basic cloud computing project that demonstrates cloud-based file storage and management.

## Introduction

Cloud storage allows users to store and access files through the internet.

## Objectives

- Learn cloud storage concepts
- Upload files
- Download files
- Manage stored files

## Features

- File Upload
- File Download
- File Viewing

## System Architecture

The Cloud Storage Explorer system consists of three main components:

1. User – Initiates file operations.
2. Web Browser – Provides the interface for accessing cloud storage.
3. Cloud Storage – Stores and manages files.

The system supports the following operations:

- Upload File
- View File
- Download File

The architecture diagram is available in the images folder.

## Conclusion

This project demonstrates basic cloud storage operations.
